# Hilfe 13 — Цифровая экосистема школы №13
Проект разработан для автоматизации школьных процессов и поддержки учеников.

## Основные функции:
*   **Умное расписание:** актуальные уроки для 8-х классов.
*   **Калькулятор оценок:** расчет итогового балла на основе процентов.
*   **Анонимная психологическая помощь:** прямая связь с поддержкой, автоматический перевод на линию 111 в нерабочее время.
*   **Информационный блок:** актуальное меню столовой, новости и важные номера.

## Технологии:
*   Python 3.10+
*   Aiogram 3.x (Asynchronous Telegram Bot API)
